# 📊 CSV Plot (PySide6)

一个基于 PySide6 + pyqtgraph 的高性能交互式数据可视化工具, 支持 CSV 和 MDF (ASAM MDF4/DAT) 格式文件, 专为快速加载, 浏览和分析时序数据而设计. 支持百万级数据点的流畅绘制和多曲线模式.

***

## ✨ 主要特性

### 🚀 强大的图表功能

- **拖拽式绘图**: 从变量列表拖拽变量到绘图区域即可绘图
- **灵活布局**: 支持多子图网格排列 (行列数可配置), 可自由调整布局
- **同步缩放**: 所有图表 X 轴自动同步 (XLink), 支持鼠标交互缩放
- **图表单线/多线模式**:
  - 模式根据曲线数量切换
  - 单线模式下, 新曲线拖入绘图区域会执行“替换”操作, 替换当前显示的曲线. 多线模式下，默认为“添加”操作
- **高性能渲染**:
  - 智能降采样 (peak 模式保留峰值特征)
  - 支持百万级数据点流畅绘制
  - 曲线样式自动切换: 缩放至细节时自动显示符号点

## 📖 使用指南

### 🖱️ 基本操作流程

> **1️⃣ 加载数据**
>
> - 点击 "导入数据文件" 按钮选择 CSV / MDF 文件; 也可以将文件拖拽到程序窗口加载
> - 点击 "重载" 按钮, 重新加载文件

> **2️⃣ 浏览数据**
>
> - 在左侧变量列表中查看所有变量
> - 观察颜色指示了解数据质量 (mdf不支持)
> - 双击变量名查看详细数据表格 (也可通过右键菜单 "添加至数值变量表" 添加)

> **3️⃣ 绘制图表**
>
> - 从变量列表, 按住鼠标左键拖拽变量到绘图区域 (按住 Shift 可拖入多个)
> - 从变量列表, 右键点击 "添加至空白绘图区" 按钮将变量添加到空白绘图区 (按住 Shift 可拖入多个)
> - 点击顶部 "调整布局" 按钮可以调整图表布局, 支持多子图网格排列 (行列数可配置)
> - 在中心绘图区域双击左键或者通过右键菜单，打开”变量编辑器“管理曲线 -> 单线模式需要从此添加额外的曲线
> - 双击中键清除单个图表

> **4️⃣ 交互操作**
>
> - 使用鼠标滚轮缩放 X 轴的范围 (以鼠标位置为中心)
> - 按住鼠标左键拖拽平移视图
> - 按住shift键+鼠标左键，框选数据区域进行放大(zoom in)
> - 鼠标放在坐标轴上，Ctrl/Shift + 滚轮缩放特定轴; 也可以双击x/y坐标轴标签设置范围
> - 对于存在多条曲线的图表, 点击图例中的曲线名, 可以调整曲线的可见性
> - 绘图区提供高度调整功能 (右键 -> "adjust height")
> - 顶部的 "时间修正" 按钮可以调整时间轴的factor和offset (单位: 秒)

> **5️⃣ 数据分析**
>
> - 使用”标记区域“按钮选择感兴趣的数据区间，查看平均值, 斜率等统计信息(ctrl + t)
> - 通过顶部的 "显示光标" 按钮可以打开cursor模式(ctrl + r), 实时显示当前鼠标位置的 X/Y 坐标值
> - 右键菜单提供了更多游标模式选项, 包括自由游标, 锚定游标, 2 个锚定游标等

> **6️⃣ 数据表格**
>
> - 双击变量名查看详细数据表格 (也可通过右键菜单 "添加至数值变量表" 添加)
> - 冻结列功能: 支持列冻结, 方便对比查看
> - 智能高亮: 选中单元格高亮 + 所在行/列浅蓝高亮
> - XY 散点图: 选中两列数据可快速绘制散点图
> - 同步滚动: 冻结列与非冻结列保持同步

> **7️⃣ 模板菜单**
>
> - 点击顶部 "模板菜单" 按钮, 可以加载模板/保存模板
> - 勾选 "自动恢复", 则会自动加载上次保存的模板, 无需手动操作

## ⌨️ 快捷键

| 快捷键 | 功能 | 说明 |
|---|---|---|
| `Ctrl + R` | 切换光标显示 | 打开/关闭光标, 实时显示鼠标位置坐标 |
| `Ctrl + T` | 切换标记区域 | 打开/关闭标记区域, 查看区间统计信息 |
| `Ctrl + Y` | 仅调节Y轴 | 在当前 X 轴范围内自动缩放 Y 轴 |
| `Ctrl + Shift + Y` | 自动缩放 | 自动缩放 X/Y 轴以显示全部数据 |
| `Ctrl + F` | 日志搜索 | 在日志窗口(Python标签页)中聚焦搜索框 |
