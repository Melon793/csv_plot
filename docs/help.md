# 📊 CSV Plot (PySide6)

一个基于 PySide6 + pyqtgraph 的高性能交互式数据可视化工具, 支持 CSV、MDF (ASAM MDF4/DAT) 与 BLF (Vector 总线日志, 搭配 DBC / ARXML 解码) 格式文件, 专为快速加载, 浏览和分析时序数据而设计. 支持百万级数据点的流畅绘制和多曲线模式.

***

## ✨ 主要特性

### 🚀 强大的图表功能

- **拖拽式绘图**: 从变量列表拖拽变量到绘图区域即可绘图
- **灵活布局**: 支持多子图网格排列 (行列数可配置), 可自由调整布局
- **同步缩放**: 所有图表 X 轴自动同步 (XLink), 支持鼠标交互缩放
- **变量拖拽**:
  - **默认拖拽变量到绘图区域执行“添加”操作**（新曲线都会追加到现有曲线列表中）
  - **按住 Shift + 拖拽变量到绘图区域执行“替换”操作**（先清空当前所有曲线，再绘制新变量）
  - 拖拽悬停时，提示文字（“释放以添加”/“释放以替换”）会根据 Shift 键状态实时切换
- **高性能渲染**:
  - 智能降采样 (peak 模式保留峰值特征)
  - 支持百万级数据点流畅绘制
  - 曲线样式自动切换: 缩放至细节时自动显示符号点

## 📖 使用指南

### 🖱️ 基本操作流程

> **1️⃣ 加载数据**
>
> - 点击 "导入数据文件" 按钮选择 CSV / MDF / BLF 文件 (快捷键 `Ctrl+O`); 也可以将文件拖拽到程序窗口加载
> - 选择 BLF 时会先弹 "指定 CAN 数据库 (DBC / ARXML)" 对话框: BLF 只记录原始报文, 需数据库才能还原出信号; 可多选文件并用 ↑/↓ 调优先级 (同一报文 ID 取靠前的库)
> - 首次之后的 BLF 导入默认自动复用上次数据库, 不再弹窗; 当前使用情况一直显示在底部状态栏的 CAN 段上, 点该段可打开抽屉查看数据库清单与未匹配明细
> - 点击 "重载" 按钮, 重新加载文件

> **2️⃣ 浏览数据**
>
> - 在左侧变量列表中查看所有变量
> - 观察颜色指示了解数据质量 (mdf不支持)
> - 双击变量名打开「变量数值表」查看完整数值 (也可通过右键菜单 "添加至变量数值表" 添加)

> **3️⃣ 绘制图表**
>
> - 在中心绘图区域双击左键或者通过右键菜单，打开”绘图变量编辑器“管理曲线（添加、删除曲线，调整样式...）
> - 从变量列表, 按住鼠标左键拖拽变量到绘图区域 (按住 Ctrl 可拖入多个)
> - 从变量列表, 右键点击 "添加至空白绘图区" 按钮将变量添加到空白绘图区 (按住 Ctrl 可拖入多个)
> - 点击顶部 "调整布局" 按钮可以调整图表布局, 支持多子图网格排列 (行列数可配置)
> - 双击中键清除单个图表

> **4️⃣ 交互操作**
>
> - 使用鼠标滚轮缩放 X 轴的范围 (以鼠标位置为中心)
> - 按住鼠标左键拖拽平移视图
> - 按住shift键+鼠标左键，框选数据区域进行放大(zoom in)
> - 鼠标放在坐标轴上，Ctrl/Shift + 滚轮缩放特定轴; 也可以双击x/y坐标轴标签设置范围
> - 对于存在多条曲线的图表, 点击图例中的曲线名, 可以调整曲线的可见性
> - 绘图区右键菜单: 跳转至变量数值表 / 按 X 范围调节 Y 轴 / 游标模式 / 显示(隐藏)游标数值 / 复制变量名 / 绘图变量编辑器 / 调整高度 (行高 25%~400%, 可全部重置为 100%) / 清除绘图
> - 点击底部状态栏的 "x轴" 段, 在弹出的抽屉里设置采样频率(或手写系数)与偏移量, 应用后所有已开子图的横轴同步重算

> **5️⃣ 数据分析**
>
> - 使用”标记区域“按钮选择感兴趣的数据区间，查看平均值, 斜率等统计信息(ctrl + t)
> - 通过顶部的 "显示游标" 按钮可以打开游标模式(ctrl + r), 实时显示当前鼠标位置的 X/Y 坐标值
> - 右键菜单提供了更多游标模式选项, 包括单自由游标, 单固定游标, 双固定游标等

> **6️⃣ 变量数值表**
>
> - 双击变量名打开「变量数值表」查看完整数值 (也可通过右键菜单 "添加至变量数值表" 添加)
> - 冻结列功能: 支持列冻结, 方便对比查看
> - 智能高亮: 选中单元格高亮 + 所在行/列浅蓝高亮
> - XY 散点图: 选中两列数据可快速绘制散点图
> - 同步滚动: 冻结列与非冻结列保持同步

> **7️⃣ 模板菜单**
>
> - 点击顶部 "模板菜单" 按钮, 可以加载模板/保存模板
> - 勾选 "自动恢复", 则会自动加载上次保存的模板, 无需手动操作

### 🚌 BLF (CAN 总线日志) 说明

BLF 只存原始报文, 必须搭配 DBC 或 ARXML 数据库才能解码出信号.

- **变量粒度**: 1 个 (总线通道, CAN ID) 报文桶 = 1 个 Group, 标签形如 `Ch1 0x1A0 EngineData (G3)`; 时间轴为相对秒且首帧归零
- **解码能力**: Intel / Motorola 字节序, 有符号补码, IEEE float32/64, 多路复用 (非本路采样点为缺口), `VAL_` 枚举表自动映射文本
- **扫描只读报文不解码**: 绘图时才向量化解码, 因此数据库选错了不必重新导入
- **换数据库**: 点状态栏 CAN 段打开抽屉, 用抽屉页脚的 "重选数据库…" 重绑即可, **不重新扫描报文**, ms 级完成
- **三态反馈**: 状态栏 CAN 段与抽屉顶部横幅同步显示 —— 绿 = 全部报文已命中数据库; 橙 = 有报文 ID 未在库中定义 (在抽屉里点 "查看" 列明细); 黄 = 报文数超 3000 万上限仅扫了前一段
- **错误帧 / 远程帧**: 跳过, 不产生采样点
- **仅覆盖 CAN / CAN-FD 报文信号**: LIN / FlexRay / 以太网对象, ENV/SYS 变量, 总线负载统计, J1939 PGN 与 UDS 诊断帧均不在范围内

## ⌨️ 快捷键

| 快捷键 | 功能 | 说明 |
|---|---|---|
| `Ctrl + O` | 导入数据文件 | 打开文件选择对话框, 加载 CSV / MDF / BLF / Excel 文件 |
| `Ctrl + R` | 切换游标显示 | 打开/关闭游标, 实时显示鼠标位置坐标 |
| `Ctrl + T` | 切换标记区域 | 打开/关闭标记区域, 查看区间统计信息 |
| `Ctrl + Y` | 仅调节Y轴 | 在当前 X 轴范围内自动缩放 Y 轴 |
| `Ctrl + Shift + Y` | 自动缩放 | 自动缩放 X/Y 轴以显示全部数据 |
| `Ctrl + L` | 修改图表布局 | 打开网格布局选择对话框, 调整行列数 |
| `Ctrl + F` | 日志搜索 | 在日志窗口(Python标签页)中聚焦搜索框 |
